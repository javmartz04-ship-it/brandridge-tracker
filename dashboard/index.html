Connect it to PostHog once. The key stays in this browser only.

  1. Open PostHog → Personal API keys and click Create personal API key.
  2. Name it Funnel HQ. Under scopes pick Query → Read only, and limit it to the Brandridge Funnels project.
  3. Copy the key (starts with phx_) and paste it below.
